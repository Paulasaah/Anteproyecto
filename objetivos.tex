\chapter{Objetivos}

\section{Objetivo general}
Desarrollar un algoritmo de inteligencia artificial basado en aprendizaje autosupervisado para clasificar lesiones cutáneas a partir de imágenes dermatológicas, orientado al apoyo del análisis clínico en el contexto del departamento de Santander.

\section{Objetivos específicos}
\begin{itemize}
    \item Caracterizar conjuntos de datos de imágenes dermatológicas representativos de lesiones cutáneas relevantes para el contexto clínico del departamento de Santander.
    \item Diseñar un algoritmo de clasificación de lesiones cutáneas basado en aprendizaje autosupervisado utilizando imágenes dermatológicas.
    \item Evaluar el desempeño del algoritmo propuesto mediante métricas reportadas en la literatura científica para tareas de análisis de imágenes médicas.
    \item Implementar un prototipo de aplicación que integre el algoritmo desarrollado para el apoyo en el análisis de imágenes dermatológicas.
\end{itemize}
